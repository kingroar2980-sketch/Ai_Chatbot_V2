 🤖 AI Specialist Assistant
A custom Gemini-powered chatbot built with Python and Streamlit.

 ✨ Features
* **Smart Memory:** Remembers user details across sessions using JSON.
* **Modern UI:** Custom dark-themed interface.
* **Dynamic Brain:** Automatically detects available Gemini models via API.

 🛠️ Setup
1. Clone the repo.
2. Install requirements: `pip install -r requirements.txt`.
3. Add your API key in `app.py`.
4. Run: `streamlit run app.py`.
